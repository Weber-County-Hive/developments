# Developments in Weber County

A map of large housing projects, annexations and financing districts in Weber County, Utah, from The Weber County Hive.

Live page: https://weber-county-hive.github.io/developments/

- `index.html`: the map and the project list
- `developments-data.js`: one entry per project. Add a project here and it shows up on the map and in the list.
- `altura.html` / `altura-plain.html`: the Altura case file and its plain-words version
- `style.css`: shared colors and layout (sage, sand, deep green)

Public records and news only.
